# Ekart — Full Stack Ecommerce Platform

A production-ready ecommerce platform built with Next.js 16

## 🚀 Live Demo
[link here]

## ⚙️ Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Sanity CMS
- Zustand
- NextAuth (Google OAuth)
- Razorpay Payments
- Tailwind CSS + Shadcn UI

## ✨ Features
- Product listing, search, filtering
- Cart + Wishlist (persisted)
- Google Authentication
- Razorpay payment integration
- Blog section via Sanity
- Fully responsive

## 🛠️ Run Locally
npm install
npm run dev

## Environment Variables
NEXT_PUBLIC_SANITY_PROJECT_ID=
SANITY_API_TOKEN=
NEXTAUTH_SECRET=
RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
